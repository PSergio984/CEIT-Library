# LLM-as-judge scores answers on four binary dimensions over golden outputs only

EVAL-03's judge is **one pinned OpenRouter model, configured not hardcoded** (`services.ai_sidecar.judge_model`) — chosen to be **stronger than, and from a different family than, the generator** (`llama-3.3-70b-instruct`, ADR 0001) to blunt self-preference bias. Calls run at **temperature 0** with **reason-before-score** ordering and a structured JSON verdict.

**Four dimensions, each scored by its own call, all binary pass/fail in v2.0** (the survey's most reliable scale): **grounding** — is every factual claim supported by the retrieved documents shown to the generator; **citation support** — does each cited record actually support the claim its `[N]` marker marks; **answer completeness** — does the answer address the question asked; **refusal correctness** — for negative cases, is the canonical refusal the right response. Marker↔payload *existence* is validated deterministically by the harness before any LLM call (a `[N]` absent from the companion-`/search` payload fails without spending a token); the judge rules only on *semantic support*. Overall result = the per-dimension vector plus an all-dimensions-pass boolean; gradated scales are deferred until binary proves too coarse.

**Scope and cost: exhaustive over golden outputs, nothing else.** `ai:eval-answers` mirrors the retrieval harness (ADR 0022): golden queries run through the production chat path (streamed, assembled), citations built via the companion `/search` call exactly as the widget does, deterministic citation check, then the four judge calls — ~50 cases × 4 dimensions ≈ 200 cheap calls per full run. **No production-conversation sampling in Phase 13** (live traffic judging belongs to Phase 14 metrics), and no automatic escalation tiers: instead, every run stores raw judge reasons alongside verdicts, and a **human spot-check of 10 randomly drawn judgments per run** (kappa against the reviewer's own read) is the standing bias guard — replacing one-off mitigations with a measurable drift detector.

_Considered (rejected):_ **judging production conversations now** — EVAL-03 scopes answer quality against golden outputs; live-traffic scoring needs the Phase 14 metric plumbing and cost guards; **anchored 0–5 Likert everywhere** — gradation invites verbosity and position biases the survey documents; binary first, add scales only where binary proves blind; **auto-escalation to a bigger judge on disagreement** — two-judge arbitration doubles cost and still lacks ground truth; human kappa review is cheaper and actually measures judge quality; **letting the LLM validate marker existence** — deterministic string matching is free and perfect; paying tokens for it would be waste.
