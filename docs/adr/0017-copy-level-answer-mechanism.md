# Copy-level answers: Laravel-side aggregation, exposed to the librarian persona as an agentic-loop tool

CHAT-06 needs librarians to get copy-level operational answers (per-title rollups, per-copy status with due-back time, overdue aggregates) without borrower PII ever reaching the LLM. We keep all aggregation **Laravel-side**: a new `CopyStatusService` mirrors `AvailabilityService`'s principles — single grouped queries over `inventories` / `borrow_transactions`, explicit column whitelists, so `user_id` and `session_token` are never selected, let alone serialized. The sidecar gains no database access and no inventory corpus.

**Delivery rides the Phase 11 agentic loop as a second function-call tool.** The sidecar registers an operations tool (alongside `rrf_search`) **only when the request's `role` is `librarian`** (ADR 0015); the tool calls back to a small token-authed internal Laravel endpoint (same `X-Sidecar-Token` trust model as every sidecar-facing route), which returns whitelisted JSON facts. The model supplies the tool arguments — `{paper}` for per-title counts, `{copy_id}` for per-copy status incl. `expires_at` as due-back, no-args for the global overdue count — so entity resolution happens inside the existing loop mechanics: pydantic `extra="forbid"` arg validation, max-3 executed rounds, and the existing empty-result canonical refusal when nothing matches. Endpoint failures surface as tool errors that degrade to the grounding refusal, never to guessed numbers.

_Considered (rejected):_ **an eager facts block in a sixth `/chat/stream` field** — a second schema amendment in one phase, forces title-matching entity resolution on *every* librarian turn (cost + wrong-entity risk), and bloats context on turns that never needed it; **stuffing facts into `query`** — already rejected by ADR 0015 (retrieval pollution, log bloat); **sidecar-side inventory corpus or direct DB access** — violates the charted strict-PII boundary and duplicates Laravel-owned state; **fully deterministic non-LLM answers** — would abandon the conversational stream for a template, against the zero-widget-change constraint.
