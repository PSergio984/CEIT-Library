# Retrieval evaluation runs as an artisan command over the production search path

EVAL-02's harness lives **Laravel-side as `ai:eval-retrieval {--corpus=} {--k=} {--format=table|json}`**, joining the existing `ai:*` command family (`ai:export-corpus`, `ai:push-corpus`, `ai:sync-index`) that already owns AI operations. It reads the golden fixtures (ADR 0021), executes each case through `AiService::search()` — the same client and `/search` endpoint production uses — resolves returned doc ids to logical keys with the fixture slugger, and scores set overlap. No sidecar-side runner: eval truth is authored and versioned Laravel-side, and a Python runner would duplicate fixture parsing and split the HTTP-client story.

**Metrics: Recall@k is the primary gate at k=5** (the generator's actual default `top_k`, ADR 0004); **Precision@k and MRR@k are secondary**. **F1@k is computed and reported as an informational derived statistic** to satisfy EVAL-02's letter, but per the survey (`research/rag-eval-practices`) nothing gates on it — harmonic means hide which side of P/R failed. Negative cases are **excluded from retrieval metrics** (they have no relevant set to score); their correctness belongs to refusal scoring, pinned by the negative-semantics ticket.

**Freshness and output**: if a fixture header's export hash mismatches the current corpus export, the command prints a loud warning and marks the report `"stale": true` rather than aborting — metrics against a drifted index still inform. Reports render as a per-corpus console table and, with `--format=json`, land as machine-readable artifacts under `storage/app/ai-eval/runs/` (runtime data, correctly gitignored — unlike datasets). **No pass/fail thresholds in v2.0**: first runs exist to establish the baseline; gating numbers get chosen once real measurements exist, not invented in advance.

_Considered (rejected):_ **sidecar-side pytest runner** — splits eval authoring (Laravel fixtures) from execution and duplicates slugger/fixture logic; **standalone script outside both codebases** — orphaned tooling nobody owns; **gating on F1@k or pre-invented thresholds** — hides failure attribution and produces arbitrary pass/fail lines before any baseline exists; **aborting on stale exports** — throws away signal precisely when the index moved.
