# Academic paper corpus shape and topic/author/year/adviser search

SEARCH-05 ("user can search academic papers by topic, author, year, or adviser") is served by evolving the existing `catalog` corpus documents (no new corpus tag — the catalog corpus IS academic papers: `CorpusExporter::exportCatalog()` is its only writer) and extending the existing `/search` filter mechanism with two new keys.

**Doc shape (D-01..D-03):** bibliographic-only, one rich index document per paper. The `text` field composes `title` (single occurrence — the Phase 8 title-doubling is dropped) plus `authors:` (semicolon-joined), `research_adviser:`, `technical_adviser:`, `dean:`, `department:`, `publication_year:`, `paper_type:`, `catalog_code:` segments, all through the existing `sanitize()` caps. "Topic" search = free-text BM25+semantic over this composed text — no abstracts, no taxonomy column (D-01 rejects abstract/summary, D-03 rejects a topics table). The `metadata` block is the filter + citation contract and is UNCHANGED: `catalog_code`, `department`, `publication_year` (int), `paper_type`, `authors` (array), `research_adviser`/`technical_adviser`/`dean` (strings), `url` `/academic-papers/{id}`. `schema_version` stays `1` — the shape change rides the existing versioned atomic rebuild (ADR 0004: no contract change).

**Filters (D-05, discretion resolved):** two new keys inside the intentionally-permissive `filters` dict — no `SEARCH_ALLOWED_KEYS` change (verified: `main.py:59,106`). `author` and `adviser` are **case-insensitive substring** matches (matches the Laravel `scopeSearch` LIKE behavior); `author` matches against any element of `metadata.authors`; `adviser` matches against `metadata.research_adviser` OR `metadata.technical_adviser` (single key, OR semantics — a reader asking "papers advised by X" means either role). Existing `paper_type`/`department`/`publication_year`/`year_from`/`year_to` keep their exact semantics. Filters apply post-retrieval pre-RRF inside `passes()` (a filtered doc can never outrank a relevant one). Unknown top-level fields still 422 (`_reject_unknown`).

**Search surface (D-04, D-06):** paper search is a tab/mode on the existing student `AcademicPaperIndex` page (no route/URL change): a Browse/Paper Search tab strip, author/adviser selects gated on tab mode, and results in sidecar RRF rank order with no sort control ("Results ranked by relevance" caption). `author`/`adviser` are included in the sidecar payload only in paper-tab mode (browse-mode payloads stay byte-identical to Phase 9/10). The status-filter force-exit (`updatedStatusFilter()` → `exitHybridMode()`) is unchanged; author/adviser are refine-only filters.

_Considered (rejected):_ an abstract/summary data source (D-01 — no schema/entry work this phase; revisit if staff want richer paper content); an explicit topics/keywords taxonomy (D-03 — revisit if free-text precision testing fails); a separate `papers` corpus tag (forks ADR 0006 chip rendering, availability hydration, chat corpus validation, similar-books — rejected, RESEARCH.md Summary); two adviser filter keys (single OR key is simpler and matches the one-tool-one-filter surface); a sidecar `exclude` param and a sort control (ADR 0011 / D-06 — both rejected at contract level).
