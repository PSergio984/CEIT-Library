| Threat | Severity | Mitigation in this plan |
|---|---|---|
| T-01 Unauthenticated access to sidecar endpoints | HIGH | HTTP middleware on ALL routes: `secrets.compare_digest(header.get("X-Sidecar-Token", ""), settings.sidecar_token)`, else 401 `{"error":{"code":"invalid_request","message":"missing or invalid X-Sidecar-Token"}}`. | T-02 Sidecar reachable from the network (public exposure anti-pattern) | HIGH | uvicorn binds `host="127.0.0.1"`, `port=8310` (configurable via `Settings.host`). Asserted in `tests/test_api.py` / documented in README. |
| T-03 Token leakage in logs or responses | HIGH | Token read only from pydantic-settings env (`.env` gitignored); never logged; error envelopes carry only `code`/`message`. |
| T-04 Malformed/tampered corpus JSON drives bad index state or crashes | MED | `ingest.load_documents()` validates `schema_version == 1`, presence of `generated_at`, required fields per doc; rejects duplicate `id`s; raises loudly (no silent partial index). |
| T-05 Query prompt-injection via search terms | LOW | Phase 8 has no LLM calls — queries only hit FTS5/embedding math; index text already truncated/sanitized at export (08-01). |
</threat_model>
