ASVS L1. Block on HIGH-severity threats. Trust boundaries relevant to this plan:

| Boundary | From → To | Trust model |
|---|---|---|
| B-1 | OpenRouter LLM (untrusted model output) → loop tool-call args → `rrf_search()` | UNTRUSTED: model output becomes search input — the new injection surface (no web tools, search-only by D-09, but args still validate) |
| B-2 | Laravel `/chat/stream` client → sidecar endpoint | Token-authenticated; closed top-level schema (ADR 0004); agentic path serves the same contract |
| B-3 | Sidecar → OpenRouter | API-keyed external call; per-call `max_tokens` (512 today) |
| B-4 | Sidecar → Laravel SSE stream | Trusted transport; frames parsed client-side as typed events (11-05) |

STRIDE Threat Register:

| ID | STRIDE | Threat | Sev | Disposition | Mitigation in this plan |
|---|---|---|---|---|---|
| T-11-08 | Spoofing | Prompt injection via tool-call params: the model emits args outside the closed schema (unknown filter keys, extra fields, wrong types, e.g. a filter value smuggling instructions) and they execute as search input | HIGH | MITIGATE | SEARCH_TOOL spec carries `additionalProperties: false` AND args parse through a pydantic model with `extra="forbid"` BEFORE any execution; query non-empty str, corpus enum, top_k int 1..50, filter keys from the ADR 0013 closed set with str/int values; a malformed call gets ONE corrective feedback turn, then fail-closed — never executed, never guessed around |
| T-11-09 | DoS | Token/cost runaway: unbounded tool rounds or LLM retries multiply OpenRouter cost per message | HIGH | MITIGATE | MAX_TOOL_ROUNDS = 3 counts executed searches (D-11); no HTTP-level retries on the stream (existing `retries: 0` posture, AiService.php:54-63); per-call `max_tokens` 512 preserved; refusal path makes ZERO LLM calls (empty-docs check before any LLM prompt); tests assert the 4th tool call is suppressed |
| T-11-10 | Tampering | Malformed-args feedback loop: repeated bad tool calls spin forever or an ungrounded answer leaks out after cap | MED | MITIGATE | One corrective feedback turn per malformed call, then fail-closed refusal (tested); cap path answers ONLY from accumulated docs, or refusal when docs are empty — never a weaker ungrounded answer (D-08) |
| T-11-11 | Info disclosure | Raw tool JSON or internal frames leak into the SSE stream (activity lines exposing args/results) | MED | MITIGATE | Activity frames are static short strings (D-12 example copy), never args/results JSON; chunk envelope `{"c": ...}` unchanged; frame emission unit-tested for exact ordering and content |
| T-11-12 | DoS | Mid-loop provider failure leaves the stream hanging or emits multiple error frames, breaking the ADR 0004 `event: error` taxonomy the Laravel client maps to AiServiceProviderException | MED | MITIGATE | Provider exception mid-loop → single `event: error` + `[DONE]` exactly like the existing one-shot path (rag.py:174-181 pattern); `[DONE]` always terminates; endpoint-level test asserts the taxonomy |
| T-11-13 | Tampering | Citation set mismatches the model's source set (fresh companion search instead of the loop's merged docs) violating ADR 0006 binding | MED | MITIGATE | Citations frame built ONLY from the merged deduped round docs, renumbered 1..N in merge order (citation_payload helper); test asserts frame payload equals the docs the final prompt saw |

No HIGH-severity threat is left without a mitigation — nothing blocks this plan.
